# 换老师与预先排课的关联

## 相关数据

| 表 | 作用 |
|---|---|
| `courses.teacher_id` | 课程当前老师。小程序「我的课程」、签到只认它 |
| `course_term_teachers`（课程 + 学期唯一） | 本学期任课老师，结算时优先用它，没有再用 `courses.teacher_id`。两者始终同步 |
| `teacher_course_grants`（老师 + 课程唯一） | 预先排课的授权：锁定状态（待签合同 / 已解锁），以及该老师在这门课上的课时费设置 |
| `session_incomes`（老师 + 课程 + 日期唯一） | 每节课的课时收入，利润记录 `profit_records` 随它走 |

## 规则（v1.0.67 起）

1. **任何地方改老师都先弹框**（`TeacherChangeDialog`），选好之前已上的课怎么算再生效：
   - 从今天起生效：之前已上的课不变；
   - 从指定日期起生效：该日之前不变，该日起改为新安排；
   - 之前已上的课全部改过来。

   弹框里列出受影响的课次、现在记在谁名下、哪些已固定。
2. 生效日起已上完的课改算到新老师；改成「未安排」时改为不记老师，课时费不再算给任何老师。
3. 生效日之前的课保持原样。其中还没结算过的课次（没有课时收入、也没有利润记录），补记给原老师。
4. 已固定月份、已打款的课次一律不动。
5. 一节课只算一位老师；重新同步时沿用已记的老师，不会因为课程老师变了就改历史。
6. 课程老师、本学期任课老师、授权三者一起更新；清空老师时同时删掉本学期任课老师记录，之后的课不会再算给旧老师。
7. 结算找老师的顺序：本学期任课老师 → 课程老师。不再按授权兜底。

## 各入口

| 入口 | 说明 | 接口 |
|---|---|---|
| 课程列表 → 老师列下拉（可搜索） | 直接换老师或改成未安排，弹框确认后保存 | `PUT /admin/courses/:id/teacher { teacherId, teacherFrom }` |
| 课程列表 → 编辑 → 安排老师 | 老师有变化时，保存前弹框 | `PUT /admin/courses/:id`（带 `teacherFrom`） |
| 预先排课 → 分配（主讲） | 课程原老师和所选老师不同时弹框，可多门课一起选 | `POST /admin/faculty/:id/grants`（带 `teacherFrom`） |
| 预先排课 → 解除主讲 | 弹框（改成未安排）；解除非主讲授权不弹框 | `DELETE /admin/faculty/:id/grants/:courseId?from=` |
| 弹框预览 | 生效日之后已上完的课次 | `GET /admin/courses/:id/teacher-change?from=` |

以下情况不弹框：小程序抢课（课程原本没有老师）、延续到新学期（新学期还没上课）。

旧老师的授权会保留，因为重新同步他上过的课时，要用到里面的课时费设置。
